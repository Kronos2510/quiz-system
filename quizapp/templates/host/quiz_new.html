How publishing works

Draft → published → closed

  • Draft: only you can see it. Add and reorder questions freely.
  • Published: participants with the access code can join and start.
  • Closed: no new attempts, but existing results and grading remain.
Locked after attempts

Questions freeze

Once the first participant starts, question edits lock so stored answers stay valid. Titles, instructions, time limits and result visibility stay editable.

Fair timing

A cap that holds

If you set both a time limit and a closing time, each attempt's deadline is the earlier of the two. The server checks the clock on every request.
